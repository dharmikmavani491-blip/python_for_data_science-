# PDS Practicals 1 to 14

Subject: Python for Data Science (BE05000231)
Academic Year: July-2026

This ZIP contains Jupyter Notebook files for Practical 1 through Practical 14, based on the supplied PDS index and the practical instructions provided.

## Practical coverage
1. Variables, data types and operators
2. List, tuple, set, dictionary and string
3. Conditional statements and loops
4. Functions and built-in modules
5. File handling
6. Exception handling
7. MySQL CRUD
8. Descriptive statistics
9. Data science lifecycle and analysis
10. NumPy
11. Pandas
12. SciPy
13. BeautifulSoup web scraping
14. Scikit-learn machine learning workflow

## Supplied data
`employee.csv` is included in this folder and is used by Practicals 8, 9 and 14.

## Practical 7
MySQL credentials must be changed in the notebook before execution.

## Practical 13
The Flipkart selectors follow the class names in the supplied practical example. Flipkart may change its HTML/classes or block automated requests, so selectors may need to be updated when the notebook is run.

## How to use
Open the required `.ipynb` in Jupyter Notebook/JupyterLab or Google Colab. Keep `employee.csv` in the same working directory for Practicals 8, 9 and 14.
